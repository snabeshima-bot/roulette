# くじ引き＆ルーレット

ブラウザで動く抽選アプリです。ビルドは不要で、HTML/CSS/JS だけで動きます。

## 演出（タブで切り替え）
- **ルーレット** … ホイールを回して、針が止まった項目が当たりです。
- **くじ箱** … 箱を揺らして紙を1枚引き、開いて結果を表示します。
- **ガラガラ** … 抽選器を回して、出てきた玉の色の項目が当たりです。

項目のリストは3つの演出で共通です。

## 機能
- 項目の追加・編集・削除（名前はその場で編集できます）
- 重み（1〜100）: 数字が大きい項目ほど当たりやすくなります。確率は一覧に表示されます。ルーレットの扇の大きさと、ガラガラの玉の数にも反映されます。
- 当たった項目を除外するモード: 一度当たった項目は次から出ません。「リセット」で元に戻せます。

## 使い方
ES Modules を使っているため、`file://` で直接開くのではなく、ローカルサーバーから開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

### GitHub Pages で公開する
リポジトリの Settings → Pages で、公開元をこのブランチの `/ (root)` に設定すると、そのまま公開できます。
